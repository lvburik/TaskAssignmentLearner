# Task Assignment Learner

This repository contains tools for preparing simulation data and training
machine-learning models to predict task assignments. It is intended to be used
with simulation data generated by
[TaskAssignmentSimulator](https://github.com/lvburik/TaskAssignmentSimulator).

## Setup

Use Python 3.10 or later. Create and activate a virtual environment, then
install the dependencies:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows, activate the environment with `.venv\Scripts\activate`.

## Simulation data

Put the simulator's JSON simulation files in a directory such as `JSON_Data/`.
The dataset builders read newline-delimited JSON records from `*.json` files;
each file should contain the simulation's world information and timestep
records. Separate training and validation simulations into different
directories to avoid evaluating on training data.

## Prepare datasets

Build an image dataset for the CNN:

```bash
python CNN_dataset_builder.py --input-dir JSON_Data/train \
  --output DataSets/CNN_train.h5
python CNN_dataset_builder.py --input-dir JSON_Data/validation \
  --output DataSets/CNN_validation.h5
```

Build a feature dataset for XGBoost or the MLP:

```bash
python XGBoost_dataset_builder.py --input-dir JSON_Data/train \
  --output DataSets/XGBoost_train.h5
python XGBoost_dataset_builder.py --input-dir JSON_Data/validation \
  --output DataSets/XGBoost_validation.h5
```

Both builders accept `--max-timesteps N` to limit the number of timesteps
processed in each simulation.

## Train models

Train the CNN, XGBoost, or MLP using the datasets prepared above:

```bash
python CNN_train.py
python XGBoost_train.py
python MLP_train.py
```

The training scripts accept command-line options for dataset paths and model
search settings; run a script with `--help` to see them. CNN training loads its
datasets into memory, so allow sufficient RAM for both training and validation
images.
